# Справочник объектов поиска и анализа
При работе с клиентами и их платежами требуется выполнять множество проверок данных на совпадение с определенными объектами.
Например, наличие указанных счетов, номеров карт, email, телефонов, ИНН и пр.
Справочник объектов поиска и анализа предназначен для хранения таких объектов. 
Основные возможности:
- ведение справочника типов объектов, указание регулярных выражений для парсинга объектов;
- ведение справочника объектов (объект, тип, дата заведения);
- ведение справочника групп, группировка объектов для организации поиска в заданной группе;
- автоматическое заполнение справочника объектов путем парсинга указанной строки;
- API для анализа произвольной строки на совпадение с объектом из справочника:
	acc407p_utl_graf.check_str(pStr IN VARCHAR2, pType IN VARCHAR2 DEFAULT 'ALL', pGrp IN NUMBER DEFAULT NULL, pMode IN VARCHAR2 DEFAULT 'LIKE') 
	параметры:
	pStr – строка для анализа (назначение платежа, счет получателя);
	pType – тип данных (ACC,CARD,..), если не указано – то поиск будет по всем типам.
	pGrp - id группы/категории/вида_проверки
	pMode - режим поиска (MATCH-точное совпадение; LIKE-поиск подстроки)
	При совпадении функция вернет само совпадение, иначе - пусто.
